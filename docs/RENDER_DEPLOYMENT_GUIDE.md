## Deployment Process

### Method 1: Using render.yaml (Recommended)

1. **Push render.yaml to your repository**
   ```bash
   git add render.yaml
   git commit -m "Add Render deployment configuration"
   git push origin main
   ```

2. **Connect Repository in Render**
   - Go to [Render Dashboard](https://dashboard.render.com)
   - Click "New +" → "Blueprint"
   - Connect your GitHub repository
   - Select the repository with `render.yaml`
   - Render will automatically create all services

### Method 2: Manual Service Creation

#### Step 1: Create PostgreSQL Database

1. Go to Render Dashboard → "New +" → "PostgreSQL"
2. Configure:
   - **Name**: `another-doctor-db`
   - **Database Name**: `another_doctor`
   - **User**: `another_doctor_user`
   - **Region**: `Oregon (US West)`
   - **Plan**: `Starter ($7/month)`

#### Step 2: Create Redis Instance

1. Go to Render Dashboard → "New +" → "Redis"
2. Configure:
   - **Name**: `another-doctor-redis`
   - **Region**: `Oregon (US West)`
   - **Plan**: `Starter ($7/month)`
   - **Maxmemory Policy**: `allkeys-lru`

#### Step 3: Deploy Backend Service

1. Go to Render Dashboard → "New +" → "Web Service"
2. Connect your GitHub repository
3. Configure:
   - **Name**: `another-doctor-backend`
   - **Region**: `Oregon (US West)`
   - **Branch**: `main`
   - **Root Directory**: `apps/backend`
   - **Runtime**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn main:app --host 0.0.0.0 --port $PORT`
   - **Plan**: `Starter ($7/month)`

#### Step 4: Deploy Frontend Service

1. Go to Render Dashboard → "New +" → "Web Service"
2. Connect your GitHub repository
3. Configure:
   - **Name**: `another-doctor-frontend`
   - **Region**: `Oregon (US West)`
   - **Branch**: `main`
   - **Root Directory**: `apps/frontend`
   - **Runtime**: `Node`
   - **Build Command**: `npm ci && npm run build`
   - **Start Command**: `npm start`
   - **Plan**: `Starter ($7/month)`

## Configuration

### Backend Environment Variables

Set these in your backend service settings:

```bash
# Core Configuration
ENVIRONMENT=production
PORT=10000  # Render sets this automatically

# Database Connection
DATABASE_URL=<automatically-set-from-postgres-service>

# Cache Connection  
REDIS_URL=<automatically-set-from-redis-service>

# Security
SECRET_KEY=<auto-generated-by-render>
ALLOWED_HOSTS=*.onrender.com,app.another.doctor,api.another.doctor

# CORS Configuration
BACKEND_CORS_ORIGINS=https://app.another.doctor,https://another-doctor-frontend.onrender.com,http://localhost:3000

# External Services
STRIPE_SECRET_KEY=<set-manually>
```

### Frontend Environment Variables

Set these in your frontend service settings:

```bash
# Core Configuration
NODE_ENV=production
PORT=10000  # Render sets this automatically

# API Configuration
NEXT_PUBLIC_API_URL=<automatically-set-from-backend-service>

# External Services
STRIPE_SECRET_KEY=<set-manually>
```

## Domain Setup

### Adding Custom Domains

1. **Backend Domain** (`api.another.doctor`):
   - Go to backend service → Settings → Custom Domains
   - Add `api.another.doctor`
   - Render will provide CNAME target

2. **Frontend Domain** (`app.another.doctor`):
   - Go to frontend service → Settings → Custom Domains
   - Add `app.another.doctor`
   - Render will provide CNAME target

### DNS Configuration

Add these CNAME records in your DNS provider (Cloudflare):

| Type | Name | Target | TTL |
|------|------|--------|-----|
| CNAME | app | `another-doctor-frontend.onrender.com` | Auto |
| CNAME | api | `another-doctor-backend.onrender.com` | Auto |

**Note**: Render provides automatic SSL certificates for all domains.

## Environment Variables Management

### Setting Environment Variables

**Via Render Dashboard:**
1. Go to service → Settings → Environment
2. Add key-value pairs
3. Mark sensitive values as "Secret"

**Via render.yaml:**
```yaml
envVars:
  - key: STRIPE_SECRET_KEY
    sync: false  # Set manually for security
  - key: SECRET_KEY
    generateValue: true  # Auto-generate secure value
  - key: DATABASE_URL
    fromDatabase:
      name: another-doctor-db
      property: connectionString
```

### Connecting Services

Render automatically provides connection strings between services:

```yaml
# Backend connects to database
- key: DATABASE_URL
  fromDatabase:
    name: another-doctor-db
    property: connectionString

# Frontend connects to backend
- key: NEXT_PUBLIC_API_URL
  fromService:
    type: web
    name: another-doctor-backend
    property: host
```

**Frontend Optimization:**
```javascript
// next.config.js optimizations
module.exports = {
  compress: true,
  generateEtags: true,
  poweredByHeader: false,
  
  // Enable static optimization

  }
```

**Backend Optimization:**
```python
# FastAPI optimizations
from fastapi import FastAPI
from fastapi.middleware.gzip import GZipMiddleware

app = FastAPI()
app.add_middleware(GZipMiddleware, minimum_size=1000)

# Database connection pooling
SQLALCHEMY_DATABASE_URL = os.getenv("DATABASE_URL")
engine = create_engine(
    SQLALCHEMY_DATABASE_URL,
    pool_size=10,
    max_overflow=20,
    pool_pre_ping=True
)
```

### CDN and Caching

**Static Asset Caching:**
- Render provides built-in CDN for static files
- Automatic gzip compression
- Cache headers set automatically

**API Response Caching:**
```python
from fastapi_cache import FastAPICache
from fastapi_cache.backends.redis import RedisBackend

# Initialize Redis cache
@app.on_event("startup")
async def startup():
    redis = aioredis.from_url(os.getenv("REDIS_URL"))
    FastAPICache.init(RedisBackend(redis), prefix="another-doctor")
```

Key advantages of Render:
- **Simple Setup**: Deploy in minutes with render.yaml
- **Automatic Scaling**: No manual configuration needed
- **Managed Databases**: PostgreSQL and Redis with backups
- **Built-in Monitoring**: Logs and metrics included
- **Affordable Pricing**: Predictable monthly costs
